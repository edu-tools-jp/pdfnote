# PDF ノート — 授業用 書き込みノート

配付プリントの **PDF** や **画像** をモニター（電子黒板・プロジェクタ）に映し、
タッチペンで書き込める授業用ノートです。Windows のタッチ対応 PC を想定しています。

**ソフトのインストール不要**（Google Chrome または Microsoft Edge が必要）。
下の URL をひらくだけで使えます。

**https://edu-tools-jp.github.io/pdfnote/**

---

## できること

- **PDF・画像の取り込み**：プリントの PDF（複数ページ可）、`.png` / `.jpg` / `.webp` 画像を取り込んでページにします。
- **ペンで書き込み**：色（6色）と太さ（4段階）を変更可能。タッチペンの筆圧で線の太さが変わります。
- **直線モード**：まっすぐな直線が引けます。
- **文字入れ（テキストボックス）**：キーボードで文字を入力して自由な位置に配置できます。
  - フォント（端末のフォントも読み込み可）・大きさ・色・**太字**・揃え位置・**縦書き**を選べます。
  - 背景を「透明／白」に切り替えられます（白にすると下の印刷を隠せます）。
  - 左上の ✥ をドラッグで移動、**右下をドラッグで大きさ変更**、× で削除。
  - 「文字」以外の道具のときは枠が消え、文字だけが表示されます。
- **消しゴム**：触れた線を丸ごと消します。
- **画像を置く**：ツールバーの **「🖼 画像」** から「写真を選ぶ」「カメラで撮る」。
  ページの上に写真が置かれ、ドラッグで移動、右下で大きさ変更（縦横比は保たれます）、× で削除。
- **投げ縄（なげなわ選択）**：**「⭕ 投げ縄」** で囲むと、中にあるものをまとめて選べます。
  - **選ぶ種類を1つずつ切替**：手書き／画像／文字／目かくしのチェックで対象を絞れます。
  - 選んだものは **カット・コピー・貼り付け・複製・削除**、**ドラッグで移動**、
    **右下で拡大縮小**、**色をまとめて変更** ができます。
  - 貼り付けは**別のページにも**できます。キーボードの Ctrl+C / Ctrl+X / Ctrl+V / Delete も使えます。
  - **選び直し**：選択中に**枠の外をタップ**すると選択が解除され、そのまま次の囲みに移れます。
  - 文字は**見えている文字のまわりを囲むだけ**で選べます（テキストボックスの枠は「文字」道具のとき以外は見えないため）。
  - **選ぶ種類は覚えます**：手書き／画像／文字／目かくしのチェックは、アプリを閉じて開き直しても前回のままです。
- **答えかくし（赤シート風）**：答えを書いた部分に「目かくし」をかぶせておけます。
  授業中は **「めくり」** にして枠をタッチすると答えが見え、もう一度タッチで隠れます。
- **元に戻す / やり直す**（Ctrl+Z / Ctrl+Y）。
- **ページは縦に連続**：**2本指で上下にスワイプ**すると次／前のページへ移れます（1本指・ペンは書き込み用）。
- **指での操作**：1本指またはペンで**書き込み**、**2本指でスクロール**、**2本指の開閉で拡大・縮小**。
- **全画面表示**：上下のメニューを隠してPDFを画面いっぱいに。**そのままペンで書き込めます**。メニューは「☰」で出し入れ（テレビ投影向け）。
- **ページ一覧**：ツールバーの **「▤ ページ一覧」** で全ページをサムネイル表示。
  - **並べ替え**：サムネイルを**長押ししてから**ドラッグして順番を入れ替え（ページの間に落とすとそこへ移動）。長押しを挟むので、指でスクロールしたときに誤って動きません。ダブルクリックでそのページを開きます。
  - **選択して操作**：サムネイルをタップで選択し、**削除／コピー／PDF書き出し**ができます。
  - **PDF書き出し**：選んだページ（書き込み・目かくしこみ）を1つのPDFファイルとして保存できます。
- **ページの追加位置**：**「＋ページ」** でPDF・画像を足すとき、**今のページの直後**か**最後**かを選べます。
- **ノートの整理**：自分で**フォルダをつくって分類**できます（フォルダの中にフォルダも作れます）。検索もできます。
- **自動保存**：書くたびに自動でフォルダへ保存されます。
- **前回の続きから**：ノートを開くと、前回最後に開いていたページから表示されます。
- **開いた直後は「移動」**：誤って線を引かないよう、ノートを開くと道具は「✋ 移動」から始まります。
- **慣性スクロール**：スワイプして指を離すと、勢いに応じてスッと滑ってから止まります。

> 写真は「ページとして追加」（＋ページ）と「ページの上に置く」（🖼 画像）の両方ができます。
> カメラ撮影は「🖼 画像 → カメラで撮る」から。カメラの使用許可を一度求められます。

## はじめかた

### 1. 起動する

Chrome または Edge で **https://edu-tools-jp.github.io/pdfnote/** をひらきます。
ブックマークするか、デスクトップにショートカットを作っておくと便利です。
初回に一度ひらいておけば、次からはネットが無くても起動します。

### 2. データフォルダを選ぶ（最初の1回だけ）

最初に **「データフォルダを選ぶ」** を押し、ノートを保存したいフォルダを選びます。

- **おすすめ**：**ドキュメントの中などに「PDFノート」フォルダを作って**、そこを選んでください。
- データがなくなるリスクを避けるため、**定期的に Google ドライブ等にバックアップ**をとることをおすすめします。
  このフォルダごとコピーすれば、それがそのままバックアップになります。
- フォルダの場所はアプリが覚えます。次回からは **「前回のフォルダを使う」→「編集を許可」** を押すだけです。

### 3. フォルダとノートをつくる

**「📁＋ 新規フォルダ」** で分類用のフォルダを作っておきます（例：`2年 化学`、`中3 理科 まとめ` など、好きな名前で）。
**「＋ 新規ノート」** → 名前と入れるフォルダを選んで作成 → **「PDF・画像を追加」** でプリントを取り込みます。

> フォルダは何個でも作れます。**フォルダの中にさらにフォルダ**を入れて、階層的に整理することもできます（例：`2年 化学 ＞ 第1章 ＞ まとめ`）。
> 新規フォルダ作成時に「入れる場所」を選べます。フォルダ自体も後から **⋯ →「場所を変える」** で別の階層へ動かせます（自分の中には入れられません）。
>
> ノートは **⋯ →「フォルダを変える」** で別フォルダへ移動、**⋯ →「コピーを作る」** で別フォルダに複製できます（コピーは元とは別物になり、片方に書き込んでももう片方には影響しません）。
>
> フォルダを削除すると、**中のサブフォルダとノートは一段上の場所に引き上げられます**（中身は消えません）。

> 上部の **「💾 保存先」** は、データそのものを置く PC 内のフォルダを選び直すボタンです。普段の整理用フォルダとは別物なので注意してください。

## 保存とバックアップのしくみ

選んだフォルダの中に、次のように **本物のファイル** として保存されます。

```
選んだフォルダ/
├── index.json            … 全ノートの目次（学年・単元・更新日）
└── notebooks/
    └── <ノートID>/
        ├── notebook.json … ページ構成と書き込み（線・目かくし）
        ├── thumb.png     … 一覧用のサムネイル
        └── assets/       … 取り込んだ PDF・画像の本体
```

- このフォルダごと Google ドライブ・USB などにコピーすれば、それがそのままバックアップになります。
- 別の PC で使うときは、同じフォルダを選べば続きから使えます。

## 道具の使い方

| 道具 | はたらき |
| --- | --- |
| ✏️ ペン | 書き込み。色・太さを選べます。筆圧で太さが変化。 |
| 📏 直線 | 始点から終点までまっすぐな線。 |
| 🧽 消す | 触れた線を消します。 |
| 🖼 画像 | 写真を選ぶ／カメラで撮って、ページの上に置きます。移動・大きさ変更ができます。 |
| ⭕ 投げ縄 | 囲んで選び、カット・コピー・貼り付け・複製・削除・移動・拡大縮小・色変更ができます。 |
| 🅣 文字 | キーボードで文字を入力します。ページをタップするとテキストボックスができ、フォント・大きさ・色・太字・揃え位置・縦書き・背景（透明/白）を選べます。左上 ✥ で移動、右下で大きさ変更、× で削除。 |
| 🟥 目かくし | ドラッグで答えを隠す枠を作ります（×で削除）。色も選べます。 |
| 👆 めくり | **授業中用**。枠をタッチすると答えが見え／隠れます。 |
| ✋ 移動 | 拡大しているときに表示位置を動かします。 |

- 上部の **「全部みせる / 全部かくす」** で、ページ内の目かくしを一括で切り替えできます。
- ページは縦につながっています。**2本指で上下スワイプ**、または下の **◀ ▶** で移動します（1本指・ペンは書き込み用）。

### 指・ペンの操作（重要）

| 操作 | 動き |
| --- | --- |
| 1本指 または ペン | 書き込み（ペン・直線・消す・目かくしのとき） |
| 2本指で動かす | スクロール（上下・左右） |
| 2本指を開く／つまむ | 拡大／縮小（ピンチ） |

- **「めくり」「移動」道具を選んでいるときは、1本指でもスクロール**できます。書き込み中に画面を動かしたいときは、2本指で動かすか、「移動」「めくり」に切り替えてください。
- ピンチは**指の間隔をある程度変えたときだけ**効くので、2本指スクロール中に誤って拡大・縮小しません。

### 全画面表示（テレビ投影向け）

- 上部ツールバーの **「⛶ 全画面」** を押すと、上下のメニューが隠れて PDF が画面いっぱいになります。
- **そのまま書き込めます**（1本指・ペン）。**2本指でスクロール／ピンチ拡大**もそのまま使えます。
- メニューを出すには右下の **「☰ メニュー」** を押します。メニュー内の **「▼ 隠す」** でまた隠せます。
- **Esc キー** または **「⛶ 全画面」** で全画面を解除します。

### キーボード操作（PCで便利）

- `Ctrl+Z` 元に戻す / `Ctrl+Y` やり直す
- `→ / ←` 次・前のページ
- `1`ペン `2`直線 `3`消す `4`文字 `5`投げ縄 `6`目かくし `7`めくり `8`移動
- 投げ縄で選択中：`Ctrl+C` コピー / `Ctrl+X` カット / `Ctrl+V` 貼り付け / `Delete` 削除 / `Esc` 選択解除
  （文字を入力しているあいだは、これらのショートカットは効きません）

## 動作環境

- **Windows 10 / 11**、タッチ対応スクリーン（タッチペン）
- **Google Chrome** または **Microsoft Edge**（新しめのバージョン）
- ※ ファイル保存に「File System Access API」を使うため、Chrome / Edge 専用です。

## 困ったとき

**「データフォルダを選ぶ」を押しても保存できない／許可が出ない**
- Chrome / Edge 以外のブラウザで開いていませんか？ `index.html` をローカルで直接ダブルクリックした場合もうまく動きません。
  **https://edu-tools-jp.github.io/pdfnote/** からひらき直してください。

**PDF の表示が遅い**
- ページ数の多い PDF や、画質の高いスキャン画像は表示に少し時間がかかります。
  プリントは 1 単元ずつ・適度な画質で取り込むのがおすすめです。

**前のフォルダを「使う」ボタンが出ない／毎回選び直しになる**
- ブラウザのデータを消すと、フォルダの記憶も消えます。その場合はもう一度フォルダを選んでください
  （中のノートは消えていません）。

**まちがえて消した**
- アプリ内の削除は元に戻せません。定期的に Google ドライブ等へバックアップをとっておくと安心です。

## 構成ファイル

```
index.html           … 画面構成
style.css            … 見た目（タッチ向けの大きめUI）
js/storage.js        … 保存層（フォルダ読み書き）
js/ui.js             … モーダル・トーストなどの部品
js/library.js        … ノート一覧・整理
js/editor.js         … ページ表示・書き込み
js/pages.js          … ページ一覧（サムネ・並べ替え・削除/コピー/PDF書き出し）
js/app.js            … 起動と画面切り替え
vendor/pdfjs/        … PDF.js（Mozilla, Apache-2.0）PDF 表示ライブラリ
vendor/jspdf/        … jsPDF（MIT）PDF 書き出しライブラリ
service-worker.js    … オフライン動作と「更新」ボタン
manifest.webmanifest … アプリとしてインストールするための情報
```

PDF 表示には [PDF.js](https://mozilla.github.io/pdf.js/)（v3.11.174, Apache License 2.0）、
PDF 書き出しには [jsPDF](https://github.com/parallax/jsPDF)（v2.5.2, MIT License）を同梱しています。
